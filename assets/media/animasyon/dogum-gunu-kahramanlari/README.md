# Doğum Günü Kahramanları

Bu klasör, çocukların kendi masallarının kahramanı olduğu kişiye özel doğum günü animasyonlarının görsel ve videolarını saklamak içindir.

İlk konsept: **Küçük Prensin Masalsı Doğum Günü** (Evren'in 3. yaşı).

Dosya adlandırma önerisi: `kucuk-prensin-masalsi-dogum-gunu.webp` ve `kucuk-prensin-masalsi-dogum-gunu.mp4`.
